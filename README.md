# Speedquizzing Helper

An app designed to help make question writing and management for Speedquizzing a bit easier

---

To access the app. You don't need to install anything and can access the current version on this link:
### https://speedquizzinghelper.netlify.app/
---
However, if you want to be able to clone the repository and make changes, read on for easy instructions.

## Installation and Running Locally

N.B. You'll need to have NPM and Node JS installed on your PC.

Once the repository is cloned to your chosen folder using GitHub. Navigate to the folder where it is cloned and open a command prompt window there and type.

`npm install`

Once that's finished run

`npm run build`

And finally when that's finished run

`npm run dev`

You should then be redirected to a new browser window where you can access the app. 

If you want to modify the source code, it's best to use an IDE like Visual Studio Code.
Any changes you make to the source code while running should also update in real-time.
